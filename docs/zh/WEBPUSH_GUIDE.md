# IronChat Web Push 推送配置指南 (RFC 8030 VAPID)

IronChat 集成了符合 W3C 与 IETF 标准的原生 Web Push 推送服务，无需安装任何第三方桥接 App，即可在 iOS、Android 与桌面端享受高可靠的锁屏通知。

---

## 零内容泄露原则 (Zero-Content Leakage)
IronChat 发送的每一条推送通知均受到严格的隐私保护约束：
- 远端服务器中继给苹果 APNs、谷歌 FCM 或微软 WNS 的消息体仅包含固定提示词：*“您收到一条端对端加密消息”*；
- **绝不包含任何明文文字、发送者身份或附件信息**，即使操作系统厂商也无法从通知中获取任何聊天内容。

---

## 多平台支持与表现特性

| 操作系统平台 | 前提要求 | 推送交互特性 |
| :--- | :--- | :--- |
| **苹果 iOS / iPadOS (16.4+)** | 必须由 Safari “添加到主屏幕”作为 PWA 运行 | 完美点亮锁屏、系统震动、未读角标、点击直达会话 |
| **安卓 Android (Chrome / Edge)** | 浏览器网页或添加到主屏幕 | 原生浮动横幅、系统提示音 |
| **苹果 macOS (Safari / Chrome)** | macOS 13 Ventura 及以上 | 桌面右上角原生通知中心横幅 |
| **Windows / Linux** | Edge、Chrome 或 Firefox | 原生操作中心弹窗提示 |

---

## 苹果 iOS (iPhone / iPad) 配置操作步骤

由于苹果安全沙盒机制限制，iOS 上的 Web Push 必须在 **添加到主屏幕** 后的独立 PWA 模式下运行：

1. 使用 iPhone 自带 Safari 浏览器打开您的聊天网址（必须为 `https://` 协议）；
2. 输入动态密码完成登录；
3. 点击 Safari 底部中央的 **分享按钮**（向上箭头的方框）；
4. 向下滚动并点击 **“添加到主屏幕”**；
5. 返回手机主屏幕，点击 **IronChat** 图标打开应用；
6. 界面弹出权限申请时，点击 **“允许”** 开启通知。

## 多设备管理与诊断

### 查看与管理已绑定的设备
1. 在聊天主界面右上角，点击三点菜单 `⋮`；
2. 选择 **“已绑推送设备”**；
3. 弹窗内将列出所有已登记的设备（如 iPhone PWA、Mac Chrome 等）及绑定时间；
4. 点击 **“发送测试推送”**，可实时验证当前设备的推送通道是否通畅；
5. 点击特定设备右侧的 **“解绑”**，可立即撤销该终端的推送下发。
